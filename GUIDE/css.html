CSS - Cascading Style Sheets

Concept: CSS Selectors & Attributes

The syllabus requires you to know Element, Class (.), ID (#), and attribute selectors (e.g., input[type="text"]).

General Code Example

/* Class Selector */
.btn { background-color: blue; }

/* Attribute Selector */
input[type="password"] { border: 1px solid black; }

Project Context: Where is this used?

File: public/css/style.css

Explanation: We styled our inputs explicitly using input[type="text"], input[type="password"] so that the styling only applies to text fields and not radio buttons or checkboxes. We used class selectors like .btn and .btn-primary to standardize button looks across the site without repeating code.

Concept: Floating Layouts

Because modern tools like Flexbox and Grid are out of scope, layouts in this syllabus rely on float: left, float: right, and clear: both.

Project Context: Where is this used?

File: public/css/style.css

Explanation: Our Navigation Bar (.navbar) uses floating. The brand logo (.navbar-brand) uses float: left, and the navigation links (.nav-links a) also use float: left so they sit horizontally next to each other. We use a clearing div (.navbar-clear { clear: both; }) at the end of the navbar to prevent the layout from collapsing.
