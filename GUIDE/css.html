1. CSS Implementation Methods & Cascading Specificity

Syllabus Theory Inclusion Methods & Priority Hierarchy

CSS rules can be applied to an HTML document through four mechanisms:

  1. External Stylesheet: Placed in a separate .css file and linked in <head> via <link rel="stylesheet" type="text/css" href="style.css">. Ideal for site-wide consistency.
  2. Internal / Embedded Style: Placed inside <style> tags within the <head>. Applies exclusively to that single document.
  3. Imported Style: Using @import url("style.css"); inside a <style> block.
  4. Inline Style: Declared directly within the HTML element tag via style="..." (e.g. <p style="color: red;">).

The Cascading Specificity Order:

When multiple conflicting rules target the same element, the browser resolves them using strict priority:

$$\text{Browser Default} < \text{External Stylesheet} < \text{Internal / Embedded} < \text{Inline Style} < \text{!important override}$$
Past Paper Alert & Traps Syntax Error Identification

Past Paper Question Trap (AY21 Q1 & AY22 Q1):

  • Invalid Property Names: The examiner writes font-type: Arial; (Invalid! Must be font-family: Arial;).
  • Missing Length Units: Writing font-size: 24; (Invalid! Lengths require explicit units like px, em, or rem: font-size: 24px;).
  • Invalid Hex Color Strings: Writing color: #blue; or color: #12345; (Hex must be 3 or 6 hex digits: #0000ff).

2. Selectors, Specificity & The 4 CSS3 Combinators

Syllabus Theory Combinator Traversal Rules

CSS combinators define exact spatial relationships between elements in the DOM tree:

Combinator Syntax Name Target Element Matched
Descendant div p (Space) Descendant Selector Matches any <p> tag located inside a <div> at any nesting depth (children, grandchildren, etc.).
Child div > p Child Selector Matches only <p> tags that are immediate direct children of <div>. (Ignored if wrapped in a <span>!).
Adjacent Sibling div + p Adjacent Sibling Matches the single <p> element that immediately follows the closing </div>, sharing the identical parent.
General Sibling div ~ p General Sibling Matches all <p> elements that appear after </div>, sharing the identical parent.

The Comma (,) vs Space ( ) Distinction:

  • li a, .dropbtn: Grouped selector. Applies the styles to all <a> tags inside <li> AND all elements with class .dropbtn.
  • li a .dropbtn: Descendant chain. Applies style only to an element with class .dropbtn that is nested inside an <a> inside a <li>.

3. Attribute Wildcard Selectors

Syllabus Theory Regex-Style Attribute Matching

CSS3 allows targeting elements by matching partial string patterns in their attribute values:

  • [attr^="val"] (Prefix Match): Matches if the attribute value begins with val.
    Example: a[href^="https://"] { padding-left: 20px; } (targets secure external links).
  • [attr$="val"] (Suffix Match): Matches if the attribute value ends with val.
    Example: a[href$=".pdf"] { background: url('pdf-icon.png') no-repeat; } (targets PDF downloads).
  • [attr*="val"] (Substring Match): Matches if the attribute value contains val anywhere.
    Example: [class*="btn-"] { font-weight: bold; } (matches btn-primary, btn-danger).
  • [attr="val"] (Exact Match): Matches when attribute exactly equals val.

4. Pseudo-Classes, Link LVHA Order & Zebra Striping

Syllabus Theory Interactive States & Structural Pseudo-Classes

The Link LVHA Rule (Strict Examination Order):

When styling hyperlinks, pseudo-classes must be declared in this exact order to avoid state override conflicts:

$$\text{:link} \longrightarrow \text{:visited} \longrightarrow \text{:hover} \longrightarrow \text{:active}$$
  • :link: Unvisited hyperlink.
  • :visited: Hyperlink already visited by user.
  • :hover: Mouse pointer hovers over element.
  • :active: Moment the element is being clicked/depressed.
  • :focus: Triggered when an input gains keyboard/tab focus.

Structural Zebra Striping:

  • Row Zebra: tbody tr:nth-child(even) { background-color: #f2f2f2; }
  • Column Zebra: td:nth-child(even), th:nth-child(even) { background-color: #e0e0e0; }

5. Pseudo-Elements & CSS Automatic Counters

Syllabus Theory ::before, ::after & counter-increment

CSS Automatic Counters allow numbering elements automatically through stylesheet rules without altering the HTML markup:

  1. counter-reset: counter_name [initial_val];: Initializes counter on parent container.
  2. counter-increment: counter_name;: Increments counter variable on target element.
  3. content: counter(counter_name);: Renders the generated numeric string inside ::before or ::after.
Past Paper Alert & Traps Slide 61 Exam Formula

Past Paper Question: "Write the complete CSS code to number all <h1> elements as 'Section 1.', 'Section 2.' and all <h2> elements as '1.1', '1.2'."

body { counter-reset: section; }
h1 { counter-reset: subsection; }

h1::before {
    counter-increment: section;
    content: "Section " counter(section) ". ";
}

h2::before {
    counter-increment: subsection;
    content: counter(section) "." counter(subsection) " ";
}

6. The CSS Box Model & Box-Sizing Math

Syllabus Theory content-box vs border-box

Every element is treated as a rectangular box comprising 4 concentric layers:

$$\text{Margin} \longrightarrow \text{Border} \longrightarrow \text{Padding} \longrightarrow \text{Content}$$
  • box-sizing: content-box (Default): $$\text{Rendered Width} = \text{width} + \text{left/right padding} + \text{left/right border}$$ Example: An element with width: 300px; padding: 20px; border: 5px solid black; renders at $300 + 40 + 10 = 350\text{px}$!
  • box-sizing: border-box: $$\text{Rendered Width} = \text{width}$$ Padding and border are absorbed inside the defined width; the content box automatically shrinks to maintain total width.

7. Float Layouts, Clearfix & Overflow Mechanics

Syllabus Theory float + clear: both

Because CSS Flexbox and Grid are out of scope in this introductory syllabus, multi-column web layouts rely on floating:

  • float: left | right: Removes element from normal inline flow and shifts it to the left/right margin.
  • The Float Collapsing Problem: When child elements float, their parent container height collapses to 0px because floated children do not occupy flow height.
  • The Clearfix Solution: Inserting an element with clear: both; directly before closing the parent restores the visual boundary.
Codebase Implementation public/css/style.css (Lines 11-57) & includes/header.php

In our project, we implemented a pure float-based navigation bar with clearing:

8. Pure CSS Dropdown Menus (Guaranteed 25M Exam Question)

Past Paper Alert & Traps AY22 Question 2 Pattern

A recurring 25-mark examination question requires writing the complete HTML skeleton and CSS rules for a pure CSS hover dropdown navigation menu.

The Core Formula:

  1. Container: position: relative; display: inline-block;.
  2. Dropdown List: display: none; position: absolute;.
  3. Hover Trigger: .dropdown:hover .dropdown-content { display: block; }.
<!-- HTML STRUCTURE -->
<ul class="navbar">
    <li><a href="home.php">Home</a></li>
    <li class="dropdown">
        <a href="javascript:void(0)" class="dropbtn">Scholarships ▾</a>
        <div class="dropdown-content">
            <a href="undergraduate.php">Undergraduate</a>
            <a href="postgraduate.php">Postgraduate</a>
        </div>
    </li>
</ul>

/* CSS STYLING */
li.dropdown { display: inline-block; }
.dropdown-content {
    display: none;
    position: absolute;
    background-color: #f9f9f9;
    min-width: 160px;
    box-shadow: 0px 8px 16px rgba(0,0,0,0.2);
    z-index: 1;
}
.dropdown-content a {
    color: black;
    padding: 12px 16px;
    text-decoration: none;
    display: block;
    text-align: left;
}
.dropdown:hover .dropdown-content {
    display: block;
}

9. CSS Preprocessors: Sass / SCSS Syntax & Loops

Syllabus Theory Variables, Mixins & Loops

CSS Preprocessors (Sass, SCSS, LESS) extend vanilla CSS with programming features:

  • Variables: Declared with $ (e.g. $primary-color: #3498db;).
  • Nesting: Nest child selectors inside parents, mirroring the HTML hierarchy.
  • Mixins vs Extend (CRITICAL DISTINCTION!):
    • @mixin & @include: Copies styles directly into each selector, increasing compiled CSS size.
    • @extend: Groups selectors together with commas (.btn, .btn-primary { ... }), creating optimized compiled CSS.
  • @for Loop with Variable Interpolation: 
    @for $i from 1 through 3 {
    .col-#{$i} {
        width: 100px * $i;
    }
}
/* Compiles to:
.col-1 { width: 100px; }
.col-2 { width: 200px; }
.col-3 { width: 300px; } */
  • Partials: SCSS files prefixed with an underscore (_variables.scss) are partials and are not compiled directly. Imported via @import 'variables';.
