1. Implementation Methods & Cascading Hierarchy

Syllabus TheoryInclusion Priority Rules

CSS rules are attached to markup through four mechanisms with strict cascading priority:

  1. External Stylesheet: Stored in an external .css file linked within <head>: <link rel="stylesheet" type="text/css" href="style.css">. Highest maintainability.
  2. Internal / Embedded Stylesheet: Enclosed within <style type="text/css"> ... </style> in <head>. Local to a single document.
  3. Imported Stylesheet: Loaded via @import url("style.css"); inside a <style> block.
  4. Inline Style: Declared directly within the opening HTML tag: <div style="color: blue;">. Highest specificity among standard rules.

Cascading Specificity Resolution:

$$\text{Browser Default} < \text{External Stylesheet} < \text{Internal Stylesheet} < \text{Inline Style} < \text{!important override}$$
Past Paper AlertProperty Spelling Traps

Past Paper Question Trap (AY21 Q1 & AY22 Q1):

  • font-type: Arial; → INVALID. Must be font-family: Arial;.
  • font-size: 20; → INVALID. Missing length units! Must be font-size: 20px;.
  • color: #green; → INVALID. Must be named color: green; or hex color: #008000;.

2. CSS Syntax Fundamentals & Length Units

Syllabus TheoryRulesets & Units

Ruleset Structure: selector { property: value; }

  • Absolute Units: px (pixels - 1/96th of an inch), pt (points - 1/72th of an inch), cm, mm, in.
  • Relative Units:
    • %: Percentage relative to parent element's computed dimension.
    • em: Relative to current element's font-size (or parent font-size).
    • rem: Root em. Relative strictly to the root <html> element's font-size.
    • vh / vw: Viewport height and viewport width percentages (100vh = 100% of screen height).

3. Core Selectors & Grouping vs Descendant Distinction

Syllabus TheorySelectors & Comma Rule
  • Universal Selector (*): Matches every element in DOM (* { margin: 0; }).
  • Type Selector (h1): Matches all instances of that HTML tag.
  • Class Selector (.className): Matches elements with class="className". Reusable.
  • ID Selector (#idName): Matches unique element with id="idName".
  • The Comma (,) vs Space ( ) Distinction (EXAM FAVORITE!):
    • li a, .dropbtn: Grouped selector. Applies identical styling to all <a> tags inside <li> AND all elements with class .dropbtn.
    • li a .dropbtn: Descendant chain. Targets an element with class .dropbtn that is nested inside an <a> inside a <li>.

5. Attribute Wildcard Selectors

Syllabus TheoryWildcard Pattern Matching
  • [attr]: Matches elements possessing attribute regardless of value.
  • [attr="val"]: Matches exact value.
  • [attr^="val"] (Starts With): Matches if attribute begins with val (e.g. [class^="btn-"]).
  • [attr$="val"] (Ends With): Matches if attribute ends with val (e.g. a[href$=".pdf"]).
  • [attr*="val"] (Contains): Matches if attribute contains val anywhere.

6. Interactive Pseudo-Classes & Link LVHA Order

Syllabus TheoryStrict Pseudo-Class Order

Hyperlink pseudo-classes must be authored in this exact order to avoid cascading state conflicts:

$$\text{:link} \longrightarrow \text{:visited} \longrightarrow \text{:hover} \longrightarrow \text{:active}$$
  • :link: Default state of unvisited hyperlink.
  • :visited: Visited link in browser history.
  • :hover: Mouse cursor rests over element.
  • :active: Element is being actively pressed down by mouse button.
  • :focus: Triggered when an input receives keyboard or tab cursor focus.

8. Pseudo-Elements & CSS Automatic Counters

Syllabus TheorySlide 61 Counter Algorithm
  1. counter-reset: counter_name [initial_val];: Initializes counter on parent container.
  2. counter-increment: counter_name;: Increments counter variable on target element.
  3. content: counter(counter_name);: Renders the computed numeric string inside ::before or ::after.
Past Paper AlertSlide 61 Exam Formula
body { counter-reset: section; }
h1 { counter-reset: subsection; }

h1::before {
    counter-increment: section;
    content: "Section " counter(section) ". ";
}

h2::before {
    counter-increment: subsection;
    content: counter(section) "." counter(subsection) " ";
}

9. The Box Model Math & box-sizing

Syllabus Theorycontent-box vs border-box

Every element is treated as a rectangular box comprising 4 concentric layers:

$$\text{Margin} \longrightarrow \text{Border} \longrightarrow \text{Padding} \longrightarrow \text{Content}$$
  • box-sizing: content-box (Default): $$\text{Rendered Width} = \text{width} + \text{left/right padding} + \text{left/right border}$$ Example: An element with width: 300px; padding: 20px; border: 5px solid black; renders at $300 + 40 + 10 = 350\text{px}$!
  • box-sizing: border-box: $$\text{Rendered Width} = \text{width}$$ Padding and border are absorbed inside the defined width; the content box automatically shrinks to maintain total width.

10. Display Property Modes & Semantic Retrofit

Syllabus Theoryblock vs inline vs inline-block
  • display: block;: Starts on a new line, takes up 100% available container width (e.g. <div>, <p>, <h1>).
  • display: inline;: Flows within text line. Ignores width, height, top/bottom margins (e.g. <span>, <a>).
  • display: inline-block;: Flows inline with text, but respects width, height, padding, and margin properties!
  • display: none;: Completely removes element from the visual Render Tree (unlike visibility: hidden which preserves whitespace).
Codebase Implementationpublic/css/style.css (Lines 157-169)

In line 163, button anchors use display: inline-block; so they sit next to each other while accepting custom padding, borders, and margins.

11. Float Layouts & Clearfix Mechanics

Syllabus Theoryfloat: left + clear: both

Because CSS Flexbox and Grid are out of scope in this introductory syllabus, multi-column layouts rely on floating:

  • float: left | right;: Pushes element to margin, causing inline content to wrap around it.
  • The Float Collapse Problem: When child elements float, their parent container height collapses to 0px because floated children do not occupy flow height.
  • The Clearfix Solution: An element with clear: both; declared at the end of the parent forces the parent container to enclose all floated children.
Codebase Implementationpublic/css/style.css (Lines 19-57)
.navbar-brand { float: left; ... }
.nav-links { float: left; ... }
.nav-links a { float: left; ... }
.navbar-clear { clear: both; }

14. Sass / SCSS Preprocessor Architecture

Syllabus TheoryVariables, Mixins, Extend & Loops
  • Variables: Declared with $ (e.g. $theme-blue: #3498db;).
  • Nesting: Nest child selectors inside parent rulesets.
  • Mixins vs Extend (CRITICAL DISTINCTION!):
    • @mixin name { ... } + @include name;: Duplicates CSS declarations into every consuming selector.
    • @extend .target;: Groups selectors together with commas (.btn, .btn-primary { ... }), generating optimized compiled output.
  • @for Loop with Variable Interpolation (#{$var}): 
    @for $i from 1 through 3 {
    .border-#{$i} {
        border: #{$i}px solid #3498db;
    }
}
/* Compiles to:
.border-1 { border: 1px solid #3498db; }
.border-2 { border: 2px solid #3498db; }
.border-3 { border: 3px solid #3498db; } */
  • Partials: SCSS files prefixed with an underscore (_reset.scss) are partials and are not compiled directly into standalone CSS. Loaded via @import 'reset';.
