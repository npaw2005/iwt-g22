JavaScript

Concept: DOM Level 0 Form Access

The syllabus specifically teaches accessing form elements using the older DOM Level 0 approach (document.formName.inputName.value) rather than modern methods like document.getElementById(). Variables are declared with var, and functions use the function keyword (no ES6 arrow functions).

General Code Example (Exam Style)

function validateForm() {
    var u = document.loginForm.username.value;
    if (u == "") {
        alert("Username is required");
        return false;
    }
    return true;
}

Project Context: Where is this used?

File: public/admin.php (Lines 264+)

Explanation: In the admin panel, we use this exact method to validate the Add User form before it is sent to the server. We trigger it using <form onsubmit="return checkAddUser()" name="addUserForm">.

function checkAddUser() {
    var username = document.addUserForm.username.value;
    if (username == "") {
        alert("Please enter a username.");
        return false;
    }
    return true;
}

Concept: Dialog Boxes

JavaScript provides three native dialog boxes: alert() (for messages), confirm() (for OK/Cancel boolean responses), and prompt() (for user input).

Project Context: Where is this used?

File: public/applications.php (Line 146)

Explanation: We use confirm() directly in the HTML onclick attribute to prevent registrars from accidentally deleting or approving an application without verifying.

<button type="submit" onclick="return confirm('Approve this application?')">Approve</button>
