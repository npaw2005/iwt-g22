3. JavaScript Details

1. DOM Level 0 Access

The syllabus exclusively teaches DOM access via the document hierarchy. Modern document.getElementById() is completely ignored in favor of document.formName.elementName.value.

Project Context: public/admin.php

When the admin creates a new user, we intercept the submission using <form onsubmit="return checkAddUser()" name="addUserForm">. Inside the JS, we write var username = document.addUserForm.username.value;. If it is empty, we `return false` to stop the PHP execution entirely, saving server resources.

2. Form Validation: Algorithmic Email Validation

Past Paper Trap: Email Validation without Regex

You will lose marks if you use Regular Expressions in exams. You must use indexOf and lastIndexOf.

function validateEmail() {
    var email = document.myForm.EMail.value;
    var atpos = email.indexOf("@");
    var dotpos = email.lastIndexOf(".");
    // @ cannot be first (atpos < 1)
    // . must be at least two chars after @ (dotpos - atpos < 2)
    if (atpos < 1 || (dotpos - atpos < 2)) {
        alert("Invalid email");
        return false;
    }
    return true;
}

3. Type Coercion & Strict Equality

Past Paper Trap: == vs ===

Exams ask for outputs of comparison scripts. == coerces types. === does not.

  • 10 == "10" is true.
  • 10 === "10" is false (Number vs String).
  • null == undefined is true.

4. Dialog Boxes & Page Redirection

alert("msg") just shows text. confirm("msg") returns true/false. prompt("msg") returns user input.

Project Context: Safe Deletions

In our project, when an admin clicks "Delete" on a user, we use an inline event: <a href="..." onclick="return confirm('Are you sure?')">. If the admin clicks Cancel, JS returns false, the hyperlink event is cancelled, and the user is saved.

5. Cookies Handling

You must know how to set and read cookies via document.cookie. To set an expiry, you manipulate a Date object.

var now = new Date();
now.setMonth(now.getMonth() + 1);
document.cookie = "username=John;expires=" + now.toUTCString() + ";";
