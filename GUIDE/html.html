1. Web Architecture & DNS Resolution

Syllabus Theory4-Phase Request Lifecycle

When an end-user navigates to a URL such as http://localhost/scholarship_system/public/login.php, the transaction is processed across four distinct infrastructural tiers:

  1. DNS Hierarchy Traversal:
    • The browser inspects local memory cache → Operating system DNS cache → Local router cache.
    • If unresolved, queries the Recursive DNS Resolver (ISP / Cloudflare 1.1.1.1 / Google 8.8.8.8).
    • The resolver walks the DNS hierarchy: queries Root Name Server (.) → identifies Top-Level Domain (TLD) Server (.com, .lk) → queries Authoritative Name Server, which responds with the target machine's numeric IPv4/IPv6 address.
  2. Transport Layer (TCP & TLS Handshake):
    • Establishes reliable transmission via the TCP 3-Way Handshake: SYN (Synchronize) → SYN-ACK (Synchronize + Acknowledge) → ACK (Acknowledge).
    • If HTTPS is enabled, establishes asymmetric cryptographic exchange (TLS Handshake) to negotiate cipher suites and shared symmetric keys.
  3. HTTP Request/Response Processing: The browser dispatches an HTTP request (Method, URI, Headers, Payload) to Apache HTTPD. Apache invokes the PHP runtime engine, executes database queries against MySQL via PDO, and responds with HTTP status (e.g. 200 OK, 302 Redirect) and an HTML text payload.
  4. Browser Rendering Pipeline:
    • DOM Construction: Parses raw HTML tokens into a tree of Document Object Model nodes.
    • CSSOM Construction: Parses linked stylesheets (style.css) into the CSS Object Model.
    • Render Tree Generation: Merges DOM and CSSOM trees, ignoring non-visual nodes like <head> and elements styled with display: none.
    • Layout / Reflow: Computes exact bounding box coordinates and pixel dimensions for every visible node.
    • Paint: Fills visual pixels on the screen (colors, borders, gradients, text).
Past Paper AlertIS1207 Q1 Rendering Trap

Past Paper Question: "Explain why script tags placed in the <head> without defer or async block HTML rendering."

Exam Solution: When the browser parser encounters a synchronous <script> tag, it immediately halts DOM construction to download and execute the script, because JavaScript can modify the DOM via document.write() or DOM APIs. This blocks the rendering pipeline until script completion.

2. URL Anatomy & Web Generations (1.0 - 5.0)

Syllabus TheoryURL Structure + Web Evolution

URL Anatomy: scheme://host.domain:port/path/filename

  • scheme: Protocol used to access the resource (http, https, ftp).
  • host: Subdomain or machine name (www, localhost).
  • domain: Registered domain name (cmb.ac.lk).
  • port: Port number on the host (Default: 80 for HTTP, 443 for HTTPS, 3306 for MySQL).
  • path: Directory path on the server filesystem (/scholarship_system/public/).
  • filename: Specific resource file requested (home.php).

3. Doctype Declarations & Character Encoding

Syllabus Theory<!DOCTYPE html> + UTF-8

Every standards-compliant HTML document must initiate with a Document Type Declaration: <!DOCTYPE html>.

  • Standards Mode vs Quirks Mode: Omitting the doctype forces the browser into Quirks Mode, causing erratic rendering and non-standard box-model calculations mimicking 1990s Netscape/IE browsers.
  • Character Encodings:
    • ASCII: 7-bit encoding containing 128 English characters and control codes.
    • ISO-8859-1 (Latin-1): 8-bit extension containing 256 Western European character sets.
    • UTF-8: Variable-width (1 to 4 bytes) Unicode encoding standard covering virtually every global human script, technical symbol, and emoji. Declared via <meta charset="UTF-8">.

4. Document Metadata, Redirection & Favicons

Syllabus Theory<meta> Attributes & Timed Redirection

Metadata tags placed within <head> communicate configuration instructions to browsers and web crawlers:

  • <meta name="description" content="...">: Summary shown in search engine result snippets.
  • <meta name="keywords" content="...">: Search index keywords.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">: Configures mobile viewport zoom.
  • Timed Refresh & Redirection via HTTP-Equiv:
    • Refresh page every 30 seconds: <meta http-equiv="refresh" content="30">
    • Delayed redirection after 5 seconds: <meta http-equiv="refresh" content="5; url=login.php">
  • Favicon Link Tag: <link rel="icon" type="image/x-icon" href="favicon.ico">
  • Base Target Tag: <base target="_blank" href="http://localhost/app/"> sets global target behavior.
Past Paper AlertMetadata Placement Traps

Past Paper Question Trap (AY22 Q1): An exam snippet shows <meta charset="UTF-8"> and <title> placed inside the <body> tag. You must identify this as an error and relocate all metadata and link tags into <head>.

5. Semantic Structural Layout Containers

Syllabus TheoryHTML5 Structural Tags

HTML5 semantic layout tags replace non-descriptive <div> elements with programmatic meaning:

  • <header>: Introductory container for page titles, branding, and hero content.
  • <nav>: Section containing primary navigational links.
  • <main>: Encloses the dominant, unique content of the document (only one <main> per page).
  • <section>: Thematic grouping of content, typically introduced by an <h2>-<h6> heading.
  • <article>: Self-contained composition that can be distributed independently (e.g. blog post).
  • <aside>: Tangentially related side content, secondary links, or sidebars.
  • <footer>: Concluding block holding copyright, legal disclaimers, and contact details.
  • Older Browser Retrofit Rule (Slide 51): Older browsers treat unknown HTML5 elements as inline. They must be styled with display: block; in CSS: header, nav, section, article, aside, footer { display: block; }

6. Text Level Semantics & Typography

Syllabus TheoryVisual vs Semantic Text Elements

HTML separates visual styling from semantic importance:

  • <h1> to <h6>: Heading hierarchy (1 is largest/most important; 6 is smallest).
  • <strong> vs <b>: <b> is purely visual bolding; <strong> signals strong semantic importance to accessibility screen-readers.
  • <em> vs <i>: <i> is visual italic; <em> signals stressed emphasis.
  • <mark>: Highlights text with default yellow background.
  • <code>: Renders text in fixed-width monospace font.
  • <sup> & <sub>: Superscript (e.g. x<sup>2</sup>) and subscript (e.g. H<sub>2</sub>O).
  • <hr>: Self-closing thematic horizontal rule divider.
  • <br>: Self-closing line break without paragraph spacing.

7. Quotations, Abbreviations & Bi-Directional Text

Syllabus Theory<q>, <blockquote>, <abbr>, <bdo>
  • <q>: Short inline quotation. The browser automatically generates quotation marks (“...”) around the content.
  • <blockquote cite="URL">: Block-level quotation. Indented from both left and right margins.
  • <abbr title="Grade Point Average">GPA</abbr>: Defines abbreviations. Browser renders a dotted bottom border and displays the title tooltip on hover.

  • <cite>: Defines title of a creative work (book, paper, song). Rendered in italics.
  • <bdo dir="rtl|ltr">: Bi-Directional Override to flip text direction.

8. Ordered, Unordered & Description Lists

Syllabus TheoryList Construction & Attributes
  • Unordered Lists (<ul>): Bulleted lists. Bullets styled via CSS list-style-type: disc | circle | square | none.
  • Ordered Lists (<ol>): Numbered lists with two critical attributes:
    • type="1|a|A|i|I": Numbering style (arabic, lowercase alpha, uppercase alpha, lowercase roman, uppercase roman).
    • start="N": Numeric start index. E.g. <ol type="a" start="8"> begins numbering at the 8th letter: 'h'!
  • Description Lists (<dl>):
    • <dt>: Description Term.
    • <dd>: Description Data/Definition (rendered with indentation).

9. Hyperlinks, Link Targets & Directory Traversal Formula

Syllabus TheoryAnchor Attributes & Traversal Rules

Anchor tags (<a>) navigate between web resources using the mandatory href attribute:

  • target="_self": Default. Opens document in current frame/tab.
  • target="_blank": Opens document in a new tab/window.
  • target="_parent": Opens in immediate parent frameset.
  • target="_top": Breaks out of all framesets to fill the entire window.
  • In-Page Fragment Bookmarks: <a href="#faq">Jump to FAQ</a> links directly to <div id="faq">.
  • Cross-Page Fragment Bookmarks: <a href="help.php#faq">FAQ</a> (No space between filename and #).

10. Image Maps & Geometric Coordinates

Syllabus Theory<map> + <area> Geometry

An Image Map enables clickable hot-spots across different geometric zones of a single raster image:

  • <img src="campus.jpg" usemap="#campus_map" alt="...">: Must have usemap prefixed with hash #.
  • <map name="campus_map">: Container element. Must match usemap string without hash.
  • <area shape="..." coords="..." href="..." alt="...">: Clickable region:
    • shape="rect": coords="x1, y1, x2, y2" (Top-left X, Y, Bottom-right X, Y). Exactly 4 integers.
    • shape="circle": coords="center_x, center_y, radius". Exactly 3 integers.
    • shape="poly": coords="x1, y1, x2, y2, x3, y3, ...". Sequential vertex pairs.

11. Complex Tables, Spans & Rendering Grids

Syllabus Theory<table>, <caption>, <thead>, <tbody>, <tfoot>

Tables organize relational 2D data grids:

  • <caption>: Table title. Must be declared immediately following <table> before any rows!
  • <thead>: Encloses header rows with <th> cells (bold and centered by default).
  • <tbody>: Encloses data rows with <td> cells.
  • <tfoot>: Encloses summary footer rows.
  • colspan="N": Merges N columns horizontally.
  • rowspan="N": Merges N rows vertically.
Past Paper AlertGuaranteed 25M Drawing Question (Q2)

The TFOOT Ordering Gotcha: In HTML specifications, <tfoot> can be written physically above <tbody>. However, the browser always renders <tfoot> at the absolute bottom! When sketching table grids on the exam paper, always draw the footer at the bottom.

12. Forms & Encoding Types (Enctype)

Syllabus Theory<form action method enctype>

Forms submit client inputs across HTTP:

  • action: Target destination script URL.
  • method="GET": Appends form data to the URL query string (?key=val). Visible, cached, bookmarkable, limited to ~2048 characters. Unsafe for credentials!
  • method="POST": Packages data within the HTTP request body. Invisible in URL bar, unbookmarkable, handles arbitrary payload size up to post_max_size.
  • Enctype Encoding Types:
    • application/x-www-form-urlencoded: Default URL-encoded string.
    • multipart/form-data: Mandatory whenever uploading files via <input type="file">. Transmits data in binary chunks.
    • text/plain: Unencoded raw text (used with action="mailto:...").
Codebase Implementationpublic/login.php (Line 43) & public/signup.php (Line 47)

In public/login.php line 43, we strictly specify method="POST": <form name="loginForm" action="login.php" method="POST" onsubmit="return checkLogin()">. This ensures passwords are not exposed in server logs or browser history.
