1. HTML Mastery

1. Basic Structure & Metadata

Every HTML document requires a foundational structure: <!DOCTYPE html>, <html>, <head>, and <body>. Metadata, titles, and stylesheet links MUST go inside the <head>.

Past Paper Trap: Invalid Metadata Placement

Exams frequently present snippets with <meta> tags or <link rel="stylesheet"> placed inside the <body> and ask you to correct it. Always move these to the <head>.

Project Context: includes/header.php

In our project, we centralized this structure in header.php. This file contains the <!DOCTYPE html>, sets the <meta charset="UTF-8">, and links our CSS. This demonstrates modularity—we write the structure once and include it everywhere.

2. Forms and Input Handling

Forms are the primary way users interact with PHP. You must know attributes like action (where data is sent) and method (GET vs POST). Every input must have a name attribute to be accessible by PHP and JS.

<form action="process.php" method="POST" name="registrationForm">
    <input type="text" name="username" required>
    <input type="password" name="pwd">
    <button type="submit">Register</button>
</form>

Project Context: public/signup.php & public/login.php

We use robust HTML forms for our authentication. In signup.php, we use method="POST" because we are transmitting passwords, which should never be sent via GET (as GET puts data in the URL). Our inputs all have name attributes matching exactly what PHP expects in $_POST['username'].

3. Semantic Tables & Spans

Tables use <table>, <thead>, <tbody>, <tfoot>, <tr>, <th>, and <td>. Exams heavily focus on merging cells using rowspan and colspan.

Past Paper Trap: Grid Drawing & TFOOT Rendering

Exams often ask you to sketch a table output. Remember: Even if <tfoot> is written BEFORE <tbody> in the HTML, the browser will ALWAYS render the footer at the very bottom of the table.

Project Context: public/admin.php

We use data tables heavily in the admin dashboard (e.g., "System Report"). We loop over database results and generate <tr> rows dynamically. If asked in the viva why we didn't use `div`s for the report, you can explain that tabular data strictly belongs in <table> tags for semantic correctness according to HTML standards.

4. Hyperlinks & Image Maps

Anchor tags <a href="..."> link pages. Image maps allow clicking different regions of a single image.

Past Paper Trap: Anchor Attributes & Map Syntax

Exams will try to trick you with <a src="..."> (wrong, should be href). For Image Maps, you MUST know the syntax: <img src="x.jpg" usemap="#mapname"> and <map name="mapname"> <area shape="rect" coords="..." href="..."> </map>. Forgetting the # in usemap is a guaranteed lost mark.
