HTML - HyperText Markup Language

Concept: HTML Forms & Inputs

Forms are used to collect user input. The syllabus focuses on standard attributes like action, method, and name. In paper exams, you are frequently asked to write HTML for a basic registration or login form.

General Code Example (Exam Style)

<form action="process.php" method="POST" name="loginForm">
    <label for="user">Username:</label>
    <input type="text" id="user" name="username" required>
    
    <input type="submit" value="Login">
</form>

Project Context: Where is this used?

File: public/login.php

Explanation: In our Scholarship System, we use this exact structure for the login and signup pages. For example, in signup.php, we use a <form> tag with method="POST" and an onsubmit attribute to trigger JavaScript validation before the data is sent to PHP.

<form name="signupForm" action="signup.php" method="POST" onsubmit="return checkForm()">
    <input type="text" name="username">
</form>

Concept: Semantic Tables

Tables are used to display tabular data using <table>, <tr>, <th>, and <td>. They are heavily tested in exams for displaying database results.

Project Context: Where is this used?

File: public/admin.php (Lines 217+)

Explanation: We used tables to create the "System Report" and "Scholarship Applications" lists. We loop through database records using PHP and echo out <tr> and <td> tags to build the table dynamically.
