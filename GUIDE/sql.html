5. SQL & Databases

1. Data Definition Language (DDL) & Relational Links

Writing perfect CREATE TABLE statements from scratch is mandatory for Q4 in the exam. You must know how to define AUTO_INCREMENT PRIMARY KEY and link tables with FOREIGN KEY (col) REFERENCES other_table(col).

Project Context: schema.sql Normalization

Our project is highly normalized. The student_scholarships table acts as a Junction Table connecting users and scholarships. This resolves a Many-to-Many relationship (Students can apply to many scholarships, Scholarships have many applicants). We used ON DELETE CASCADE so orphan data is automatically cleaned up by MySQL.

2. PHP Database Execution (Prepared Statements)

The syllabus requires you to connect to the database, write a query, execute it, and fetch the results using procedural or OOP methods.

Project Context: admin.php Statistics

To generate the "System Report", we execute SELECT COUNT(*) FROM scholarships using PHP PDO. We use prepared statements everywhere (e.g. $stmt = $conn->prepare("INSERT..."); $stmt->execute([...]);) to prevent SQL Injection attacks. If asked in the viva why we used `prepare()` instead of `query()`, explain it protects the database from malicious user inputs.

3. Complex Joins

You must know how to retrieve related data across multiple tables using INNER JOIN.

Project Context: The Registrar Dashboard

In applications.php, we run a complex join: SELECT ss.*, u.username, s.name FROM student_scholarships ss INNER JOIN users u ON ss.student_id = u.id INNER JOIN scholarships s ON ss.scholarship_id = s.id. This brings together the application data, the student's name, and the scholarship's title into a single, highly efficient result set.
