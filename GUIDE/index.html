📋 UCSC IS1207 Examination Blueprint (100 Marks)

Question Primary Domain Format & Tested Capabilities High-Yield Exam Focus Areas
Question 1 (25M) HTML & CSS Syntax Errors Identify whether given snippets are valid or invalid; rewrite corrected versions. <meta> inside body, href vs src in anchors, image map usemap="#name" syntax, CSS property spelling (font-family vs font-type), length units (px), Sass @for loops & variable interpolation.
Question 2 (25M) Visual Output Prediction & UI Components Sketch rendering grids, predict CSS cascade/combinators, write complete CSS widgets. Table rendering with intersecting rowspan and colspan, <tfoot> positioning gotchas, pure CSS hover dropdown menus (display: none to block), CSS counters.
Question 3 (25M) JS & PHP Tracing, Server Configurations Trace script execution outputs, classify web server vs runtime directives. JS strict (===) vs loose (==) equality, modulo loop outputs, PHP type juggling (+ vs .), array auto-indexing, foreach reference leaks (&$val), Apache httpd.conf vs PHP php.ini directives.
Question 4 (25M) Relational SQL & PHP Backend Architecture Write complete DDL schemas with Foreign Keys, construct DML CRUD queries, write modular PHP connection scripts. CREATE TABLE with composite PKs & FKs, modular configuration (value.php + con.php), PDO / MySQLi prepared statements (prepare(), execute()), multi-table JOIN queries rendered into HTML tables.
