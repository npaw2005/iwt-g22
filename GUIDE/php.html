PHP - Hypertext Preprocessor

Concept: Superglobals ($_POST, $_GET, $_SESSION)

PHP uses superglobals to collect form data and manage user state. The syllabus emphasizes using $_POST for secure form submissions (like login) and $_GET for URL parameters. $_SESSION is critical for maintaining a logged-in state.

General Code Example (Exam Style)

<?php
session_start();
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
    $user = $_POST['username'];
    $_SESSION['user'] = $user;
    header("Location: dashboard.php");
}
?>

Project Context: Where is this used?

File: public/login.php (Lines 2-25)

Explanation: In our project, we use session_start() at the very top of every PHP file. In login.php, we check if ($_SERVER['REQUEST_METHOD'] === 'POST') to see if the user clicked login. We then capture $_POST['username'] and if the database match is successful, we set $_SESSION['user_id'] = $user['id'].

Concept: Array Mechanics & References

Past papers frequently ask you to predict the output of array assignments (e.g., implicit indexing where $arr[] = 56 assigns to the next available integer key) and the foreach reference leak gotcha (foreach($arr as &$val)).

General Code Example (Exam Style)

<?php
$nums = [1, 2, 3];
foreach ($nums as &$n) { $n *= 2; }
$n = 100; // This overwrites the last element!
print_r($nums); // Output: [2, 4, 100]
?>

Concept: PHP & Server Configuration

Exams test your knowledge of Apache vs PHP configuration directives.

  • Apache (httpd.conf): ServerRoot, DocumentRoot, LoadModule, PHPIniDir
  • PHP (php.ini): upload_max_filesize, display_errors
